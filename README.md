# 印尼盾记账（Rupiah Ledger）

Windows 本地记账软件，货币单位为印尼盾（Rp）。

- 数据保存在本机 SQLite
- 支持每笔流水上传凭证图片
- 按月导出 Excel（格式对齐原「日记账」模板，图片一并嵌入）
- 提供 NSIS 安装包，适配 Windows 10 x64（含 21H2）

## 给其他电脑用（不需要 Node / npm）

安装包已自带运行环境（内嵌 Electron），**目标电脑不需要安装 Node.js、Python 或任何开发工具**。

1. 把 `release/印尼盾记账-Setup-*.exe` 拷到对方电脑  
2. 双击安装（Win10/11 64 位）  
3. 从桌面或开始菜单打开「印尼盾记账」

首次打开若被 Windows 智能筛选拦截：点「更多信息」→「仍要运行」即可（未做代码签名时常见）。

开发命令 `npm run dev` **仅本机改代码时使用**，不要发给其他用户。

## 安装包位置

`rp-ledger/release/印尼盾记账-Setup-1.1.1.exe`

## 开发运行（仅开发机）

需要 Node.js 20+。

```bash
cd rp-ledger
npm install
npm run dev
```

## 重新打包

```bash
npm run dist
```

## 数据位置

`%APPDATA%\印尼盾记账\data\`（开发模式下可能为 `%APPDATA%\rp-ledger\data\`）

- `ledger.sqlite`：账本数据库
- `images\`：凭证图片文件

## 功能说明

| 模块 | 说明 |
|------|------|
| 记账明细 | 日期、支付方式、分类、收入/支出、金额、余额、单据、备注、核对 |
| 凭证图片 | 每笔流水可上传多张图片；点击预览，右键删除 |
| 账户汇总 | 期初 / 收入 / 支出 / 当前余额 |
| 分类统计 | 按分类汇总支出、收入、笔数 |
| 设置 | 维护支付方式、分类、单据类型与期初余额 |
| 导入 | 从旧版「日记账_新版」Excel 一键导入（合并 / 清空后导入），含嵌入图片 |
| 导出 | 选择月份 →「导出本月 Excel」 |

菜单栏为中文：文件 →「从旧 Excel 导入…」/「导出本月 Excel…」。

### 导出 Excel 工作表

1. **记账明细**（含缩略图列）
2. **凭证图片**（大图页，逐张嵌入）
3. **账户汇总**
4. **设置**
5. **分类统计**
